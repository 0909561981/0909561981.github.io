## 專案簡介

《Endless Shooter》是一款基於網頁的射擊遊戲，結合了角色升級、排行榜、登入註冊等完整功能，提供玩家良好的遊戲體驗。遊戲採用前端技術實現，並以模組化架構組織程式碼，方便維護與擴展。

---

## 主要功能

- **玩家登入與註冊**：保障玩家資料與遊戲進度保存。
- **遊戲主畫面**：包含虛擬搖桿控制、敵人生成、BOSS 戰等豐富玩法。
- **升級系統**：玩家可透過遊戲中獲得資源進行能力升級。
- **排行榜**：顯示玩家最高分數，提升競爭樂趣。
- **歷史紀錄**：查看玩家過去遊戲成績。
- **背景音樂與音效**：營造沉浸式遊戲環境。

## 注意事項

- `api.js` 需配合後端伺服器使用，請確認伺服器狀態與 API 路徑。
- 遊戲依賴 `p5.js` 函式庫，請勿刪除或移除。
- 若本地測試出現跨域問題，建議使用本地伺服器（例如 Live Server、ngrok 等）來執行。
